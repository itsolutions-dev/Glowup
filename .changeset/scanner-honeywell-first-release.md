First release: the imager of Honeywell mobile computers (the CT40 and the others the Data
Collection SDK 1.97 reaches) behind `@its/glowup-device/scanner`, as an Android Expo module, its
adapter and its config plugin. Measured on a CT40 with an IH40: QR, Code 128, EAN-13 and Data
Matrix with their AIM ids, every other symbology off for the app's claim, EAN and UPC with every
digit, UTF-8 text, the hardware, software and IH40 triggers, the release in the background. The
app supplies Honeywell's `DataCollection.aar` (`dataCollectionAarPath`): the package ships no
SDK.
