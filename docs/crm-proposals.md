# Proposed component updates from the CRM

Changes to the library proposed while building the Databeasy CRM on Glowup. Each entry is a library change,
independent of how the CRM uses it. New findings get the next number.

| #   | Component                                       | Gap                                                                                                                  | Proposed change                                                                                                                                                                                                                        |
| --- | ----------------------------------------------- | -------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| P1  | `Avatar`                                        | Always rendered as a `Pressable`, even without `onClick`: inside a pressable parent it takes the press meant for it. | Without `onClick`, render a plain `View`: no role, no press feedback, presses go to the parent.                                                                                                                                        |
| P3  | `Menu`                                          | No room for a header above the items (e.g. who is signed in).                                                        | A `header` slot (node) rendered above the first item, followed by the menu's divider.                                                                                                                                                  |
| P4  | `DrawerItem` (collapsed `Drawer`)               | Collapsed, an item shows only its icon, with no way to read its label.                                               | When the drawer is collapsed, a `Tooltip` with the item's label, on the trailing side, on hover and on focus.                                                                                                                          |
| P6  | Link-capable pressables                         | `href` exists only on the navigation items; no other exported pressable can be a link.                               | `href` (through `LinkProvider`) on `Button`, `IconButton`, `Chip` and an exported `Pressable`: a plain click navigates, Ctrl/⌘-click and middle-click open a new tab, and web renders an anchor.                                       |
| P7  | Gradient buttons (`gradientStyle`)              | No disabled variant: a disabled gradient button only fades.                                                          | A disabled state for gradient buttons using the MD3 disabled container and content tokens.                                                                                                                                             |
| P10 | `Slider`                                        | No range mode.                                                                                                       | A range mode with two thumbs and a `[min, max]` value.                                                                                                                                                                                 |
| P11 | `ToggleButtonGroup`                             | No label, and no colour role per option.                                                                             | A `label` prop, and a per-option colour role (e.g. a tri-state yes / no / any where yes and no carry different roles).                                                                                                                 |
| P13 | `IFrame`                                        | Takes only `src`; an HTML string (an email body, a template preview) has to be turned into a `data:` URL.            | A `srcDoc` prop, sandboxed by default.                                                                                                                                                                                                 |
| P14 | `Autocomplete` (`multiple`, `allowCustomValue`) | Typed text that is a valid value does not become a chip on its own.                                                  | A `createOption` (or `onCreateOption`) hook that turns valid typed text into a chip on Enter, comma or blur.                                                                                                                           |
| P15 | `SpeedDial`                                     | No badge on an action (e.g. unread messages).                                                                        | A per-action `badge`, like `IconButton`'s.                                                                                                                                                                                             |
| P16 | `FAB`                                           | No colour role (its `variant` is only icon / extended / animated): a destructive action (hang up) cannot be red.     | A `color` prop taking the MD3 roles (`primary`, `secondary`, `tertiary`, `error`), as `Button` and `IconButton` do.                                                                                                                    |
| P17 | Charts (`@its/glowup-charts`)                   | The tooltip shows only the series values.                                                                            | A custom tooltip content slot (render function receiving the hovered datum), so extra lines can be shown.                                                                                                                              |
| P18 | `Dialog`                                        | No width above 800 px; a wide table or a two-column form needs about 1040 px.                                        | A `width="xl"` option.                                                                                                                                                                                                                 |
| P19 | `Accordion`                                     | The title takes only a string, so a data row cannot be the expandable summary.                                       | A `summary` slot taking any content.                                                                                                                                                                                                   |
| P22 | `Select`                                        | No `required` prop (no required marker or validation state).                                                         | A `required` prop, as `Input` has.                                                                                                                                                                                                     |
| P24 | Colour field                                    | No colour picker; a colour setting is typed as text.                                                                 | A `ColorField` (swatch, palette from the theme, hex input).                                                                                                                                                                            |
| P25 | Icon field                                      | No icon picker.                                                                                                      | An `IconField` / `Select` variant listing icon names with their glyph and a search. The playground's `site/IconPicker.tsx` can be the starting point, but it has to move into `packages/ui`: an app cannot import from the playground. |
| P26 | `ScatterChart`                                  | No `xDomain`: the x axis spans only the data, not a chosen window (e.g. two weeks).                                  | An `xDomain?: [Date \| number, Date \| number]` prop, as `yDomain`.                                                                                                                                                                    |
| P27 | `ScatterChart`                                  | No icon markers: a point cannot carry its category's icon.                                                           | A per-point `icon` (or a `marker` render callback, as `BarChart` has) drawn inside the dot.                                                                                                                                            |

## Parked

Kept for when a real screen needs them; not to be built before.

- **P28** (`Portal` / `PortalHost`): overlays measure against the window, so a host scoped to part of the screen (inside a
  page region) places them wrongly; proposed a named `PortalHost` scoped to its own box, with overlays positioned against
  that box. The overlays of dialogs and sheets did not need it (the CRM's track G): their portals cover the whole window.

## Rejected

- **P5** (`NavigationRail` with ~30 destinations, scrolling and groups): the rail is for 3–7 destinations. The CRM's side
  menu is the `Drawer`, with collapsible groups and the collapsed mode; P4 gives it the one thing it lacked.
