# Proposed component updates from the CRM

Changes to the library proposed while building the Databeasy CRM on Glowup. Each entry is a library change,
independent of how the CRM uses it. New findings get the next number.

| #   | Component                                        | Gap                                                                                                                                                | Proposed change                                                                                                                                                                                  |
| --- | ------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| P1  | `Avatar`                                         | Always rendered as a `Pressable`, even without `onClick`: inside a pressable parent it takes the press meant for it.                               | Without `onClick`, render a plain `View`: no role, no press feedback, presses go to the parent.                                                                                                  |
| P2  | `ThemeProvider`                                  | No initial or controlled mode: it always starts light and changes only through `toggleTheme`.                                                      | An `initialMode` prop (`light` / `dark` / `system`), and a controlled pair `mode` + `onModeChange`, so an app can start in a stored choice with no flash of the other theme.                     |
| P3  | `Menu`                                           | No room for a header above the items (e.g. who is signed in).                                                                                      | A `header` slot (node) rendered above the first item, followed by the menu's divider.                                                                                                            |
| P4  | `DrawerItem` (collapsed `Drawer`)                | Collapsed, an item shows only its icon, with no way to read its label.                                                                             | When the drawer is collapsed, a `Tooltip` with the item's label, on the trailing side, on hover and on focus.                                                                                    |
| P5  | `NavigationRail`                                 | Holds 3–7 destinations and does not scroll; an app with ~30 destinations cannot use it.                                                            | Scroll its content past the available height, and accept groups and dividers as `Drawer` does.                                                                                                   |
| P6  | Link-capable pressables                          | `href` exists only on the navigation items; no other exported pressable can be a link.                                                             | `href` (through `LinkProvider`) on `Button`, `IconButton`, `Chip` and an exported `Pressable`: a plain click navigates, Ctrl/⌘-click and middle-click open a new tab, and web renders an anchor. |
| P7  | Gradient buttons (`gradientStyle`)               | No disabled variant: a disabled gradient button only fades.                                                                                        | A disabled state for gradient buttons using the MD3 disabled container and content tokens.                                                                                                       |
| P8  | `DataGrid` (and `FlatList` on web)               | A list mounted with no rows keeps its first render window when rows arrive that do not fill it: about 10 rows show and `onEndReached` never fires. | Re-measure (or remount the virtualized list) when its data goes from empty to filled.                                                                                                            |
| P9  | `DataGrid` columns                               | A column is either a fixed width or flex with a 150 px minimum; a table of six columns scrolls sideways at 1024 px.                                | A per-column `minWidth` that works together with `flex`, as `TableCell` already allows.                                                                                                          |
| P10 | `Slider`                                         | No range mode.                                                                                                                                     | A range mode with two thumbs and a `[min, max]` value.                                                                                                                                           |
| P11 | `ToggleButtonGroup`                              | No label, and no colour role per option.                                                                                                           | A `label` prop, and a per-option colour role (e.g. a tri-state yes / no / any where yes and no carry different roles).                                                                           |
| P12 | `Paper`, `Chip`, `Select`, `SpeedDial` (actions) | No `testID`; `Select`'s options list is virtualised, so off-screen options cannot be reached by role in tests.                                     | Accept `testID` like the other components, on `SpeedDial` per action too.                                                                                                                        |
| P13 | `IFrame`                                         | Takes only `src`; an HTML string (an email body, a template preview) has to be turned into a `data:` URL.                                          | A `srcDoc` prop, sandboxed by default.                                                                                                                                                           |
| P14 | `Autocomplete` (`multiple`, `allowCustomValue`)  | Typed text that is a valid value does not become a chip on its own.                                                                                | A `createOption` (or `onCreateOption`) hook that turns valid typed text into a chip on Enter, comma or blur.                                                                                     |
| P15 | `SpeedDial`                                      | No badge on an action (e.g. unread messages).                                                                                                      | A per-action `badge`, like `IconButton`'s.                                                                                                                                                       |
| P16 | `FAB`, `IconButton`                              | No colour role: a destructive action (hang up) cannot be red.                                                                                      | A `color` prop taking the MD3 roles (`primary`, `secondary`, `tertiary`, `error`), as `Button` does.                                                                                             |
