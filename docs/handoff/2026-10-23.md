## Come rifare il PDF protetto

Nessun PDF protetto è nella repo. Si genera così: `site/samplePdf.ts` scritto su file con Node (`import` diretto del `.ts`, Node 24), poi `qpdf --encrypt utente proprietario 256 -- sample.pdf protetto.pdf` (qpdf 12.4.2, zip portatile da GitHub, nessuna installazione). Il file e qpdf stanno nella cartella temporanea della sessione e non sono salvati nel repo.
